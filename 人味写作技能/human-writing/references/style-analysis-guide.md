# 写作样本分析指南

## 概述

本文档说明如何通过分析用户的写作样本，自动提取风格特征并生成个性化配置。

## 分析流程

### 第一步：收集样本

**样本要求**：
- 长度：500-2000字（越长越准确）
- 类型：用户自己写的文章（博客、日记、邮件、评论等）
- 数量：1-3篇（多篇可提高准确性）

**不适合的样本**：
- AI生成的文章
- 大量引用他人内容的文章
- 纯技术文档或数据报告

### 第二步：分析维度

#### 1. 正式程度（formal_level）

**分析指标**：
- 用词正式度：是否使用"因此"、"然而"等正式词汇
- 句子复杂度：平均句子长度、嵌套结构
- 缩写使用：是否使用"it's"、"don't"等缩写
- 口语化程度：是否使用"挺"、"贼"等口语词

**评分标准**：
- 0.0-0.3：非常口语化（大量俚语、网络用语）
- 0.3-0.5：偏口语化（日常对话风格）
- 0.5-0.7：中性（正式与口语兼顾）
- 0.7-0.9：偏正式（书面语为主）
- 0.9-1.0：非常正式（学术、公文风格）

#### 2. 俚语使用（slang_usage）

**分析方法**：
- 检测网络用语：yyds、绝绝子、破防等
- 检测口语词汇：贼、挺、那啥、这波等
- 检测方言词汇：咋整、整挺好等

**评分标准**：
- 0.0：从不使用
- 0.3：偶尔使用
- 0.5：适度使用
- 0.7：经常使用
- 1.0：大量使用

#### 3. 常用词汇（favorite_words）

**提取方法**：
- 统计高频词汇（排除常用词如"的"、"是"、"在"）
- 识别有个人特色的词汇
- 记录口头禅和习惯用语

**示例输出**：
```json
{
  "favorite_words": ["贼", "挺", "那啥", "这波", "绝了", "感觉"]
}
```

#### 4. 句子模式（sentence_pattern）

**分析指标**：
- 句子长度变化：长短句比例
- 句子结构：简单句/复合句比例
- 节奏感：是否有规律的句式变化

**分类**：
- uniform：句子长度均匀，结构相似
- mixed：长短句混合，结构多样
- varied：高度变化，节奏感强

#### 5. 情感表达（emotional_expression）

**分析指标**：
- 情感词汇密度："喜欢"、"讨厌"、"开心"等
- 感叹号使用频率
- 主观表达比例："我觉得"、"我认为"

**分类**：
- low：情感表达克制，偏理性
- moderate：适度表达情感
- high：情感表达强烈，有感染力

#### 6. 细节偏好（detail_level）

**分析指标**：
- 描述详细程度：是否有具体的场景、数据
- 例子使用频率
- 细节展开程度

**评分标准**：
- 0.0-0.3：简洁，点到为止
- 0.3-0.6：适度细节
- 0.6-1.0：详细描述，大量举例

#### 7. 个人经验（personal_experience）

**分析指标**：
- 第一人称使用频率："我"
- 个人经历引用：是否常分享自己的故事
- 主观体验表达：是否有"我感觉"、"我经历过"

**判断**：
- true：经常使用个人经验
- false：较少使用个人经验

### 第三步：生成配置

基于分析结果，自动填充配置文件：

```json
{
  "expression_style": {
    "formal_level": 0.6,
    "slang_usage": 0.3,
    "sentence_pattern": "mixed",
    "favorite_words": ["贼", "挺", "那啥"]
  },
  "cognitive_level": {
    "detail_level": 0.7,
    "example_preference": 0.8
  },
  "writing_preferences": {
    "emotional_expression": "moderate",
    "personal_experience": true
  }
}
```

### 第四步：用户确认

向用户展示分析结果，询问是否准确：

**示例对话**：
```
AI：根据您的写作样本，我分析了您的风格特征：
- 正式程度：6/10（中性偏口语）
- 俚语使用：偶尔使用
- 常用词汇：贼、挺、那啥
- 情感表达：适度
- 细节偏好：喜欢详细描述
- 个人经验：经常分享

这个分析准确吗？如有偏差请告诉我。
```

用户可以：
- 确认：保存配置
- 微调：调整特定参数
- 重新分析：提供新的样本

## 分析示例

### 示例：分析一段用户样本

**用户样本**：
```
远程办公这事儿，我觉得挺有意思的。一开始我也挺担心，觉得在家肯定偷懒摸鱼。结果真试了才发现，效率反而更高。最大的变化是不用通勤了，每天能多睡一小时。还有就是可以穿睡衣开会，这感觉贼爽。
```

**分析结果**：
```json
{
  "formal_level": 0.4,
  "slang_usage": 0.5,
  "favorite_words": ["挺", "贼", "这事儿"],
  "sentence_pattern": "mixed",
  "emotional_expression": "moderate",
  "personal_experience": true,
  "detail_level": 0.6
}
```

**分析说明**：
- formal_level=0.4：偏口语化，有"这事儿"、"贼爽"
- slang_usage=0.5：适度使用口语词
- favorite_words：提取了"挺"、"贼"、"这事儿"
- personal_experience=true：使用了"我"和个人经历

## 注意事项

1. **样本质量**：样本越长越准确，建议至少500字
2. **样本数量**：多篇样本可提高准确性，建议2-3篇
3. **样本类型**：最好是用户日常写作风格，而非特定任务风格
4. **持续优化**：配置生成后，通过使用反馈持续调整

## 与问答初始化对比

| 对比项 | 样本分析初始化 | 问答初始化 |
|--------|----------------|------------|
| 客观性 | 更客观（基于实际写作） | 较主观（用户自评） |
| 速度 | 更快（一次提交） | 较慢（多次问答） |
| 适用场景 | 有现成写作样本 | 无写作样本的新用户 |
| 准确性 | 更高（实际行为） | 可能偏差（认知偏差） |

**推荐**：优先使用样本分析初始化，无样本时使用问答初始化。
