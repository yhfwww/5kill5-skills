# 研究与验证

在这里的“验证”指策略与实现的可证伪检验，不是搜索到一段有利的历史区间。先保留策略、数据和成本三个版本，再比较实验结果。

## 1. 建立可复现的研究记录

研究开始前先完成数据源适配和质量闸门：明确供应方、交易所/市场、数据集、精确 symbol、UTC 区间、事件时钟、允许延迟、获取方式、SDK/API 版本和已知修订。先验证一个小样本文件，再扩大下载；不得把接口成功、symbol 存在或返回非空 DataFrame 当作覆盖完整的证据。详细要求见 [市场数据源适配](market-data-source-adapters.md)、[市场数据质量闸门](market-data-quality-gates.md) 和 [数据来源快照与追踪](data-provenance-and-snapshots.md)。

对逐笔成交、订单簿、mark/funding、OI 和 liquidation 等数据，保存真实文件 schema、时间戳单位、数量/合约单位、来源修订状态与缺口清单。若数据源发布修订，必须标记受影响实验并决定是否重跑，不能静默覆盖旧结果。

每一个结论至少关联以下信息：

| 内容 | 应保存的证据 |
|---|---|
| 假设 | 信号的经济含义、预计通过什么机制兑现，以及明确的反例 |
| 数据 | 供应方、市场/合约身份、时区、采样频率、覆盖区间、缺口和修订方式 |
| 策略版本 | 信号和仓位代码版本、配置快照、阈值与权重、随机种子（如有） |
| 执行假设 | 用于入场与退出的价格、延迟、成交规则、费率、滑点、资金/借贷及其他成本 |
| 结果 | 样本数、独立事件定义、净收益、成交额、回撤、持有期、失败和被过滤信号 |

不要把启动时刻、虚拟头寸成本锚、篮子权重、beta、阈值中心或历史状态静默改掉。它们改变的往往是策略含义，而非单纯“清零”或“重启”。经济参数发生变化时，应把新旧版本隔离比较；带仓切换须先定义迁移和对账规则。

## 2. 数据与信号完整性

- 只有在决策时确实可获得的数据才可进入回测。明确 bar 是闭合后可用还是正在形成；禁止未来函数、幸存者偏差和使用事后修订的成分/交易规则。
- 多腿策略先校验每条腿的合约、币种、企业行为/换月处理、报价时间和可交易性。跨腿不同步可能制造不存在的价差。
- 将“行情采样频率”与“可交易决策频率”分开。高频监控可以服务风控，但同一分钟或同一根 bar 反复调档会放大噪声和成本。
- 为缺价、过期、宽点差、异常深度、请求耗时、时钟偏差和交易所状态准备可观察的拒绝原因。新开仓/加仓应 fail closed；已有风险的减仓、平仓路径要单独设计并记录限制。

## 3. 回测与成本模型

以可成交价格而不是中间价评价可捕获收益：入场买入以 ask、卖出以 bid 起步；在此基础上按订单规模和盘口深度估计滑点，并加入账户实际费率、资金费、借贷费、交易/链上费用及延迟。若某价格、成交回报或 SDK 模拟已含某项费用，不再重复扣减。

将结果至少按以下维度拆分：

- 毛收益、净收益、每单位单边/双边成交额的净优势、换手与持仓时间；
- 最大回撤、最大不利偏移、尾部损失、连续亏损与容量敏感性；
- 市场时段、事件窗口、周末/休市、流动性水平、信号层级和退出原因；
- 计划成交与实际/纸面成交之间的偏差。

胜率和累计收益不足以决定是否可交易。小于或接近摩擦成本的毛优势，应先做成本压力测试；任何合理成本假设即可翻负的策略，不能以扩大资金解决问题。

## 4. 参数和模型实验

用预先写明的实验矩阵而非临时挑选“最好看”的组合。每个实验只改变少数要素，始终保留一条基线路径。常见的低风险优先实验包括：

- 降低同一决策周期的重复动作；只使用已结束 bar 做确认；
- 不对称进入/退出阈值、单次最大调仓档位和动作冷却；
- 单档实盘与多档 shadow 的对照；
- 固定、慢速、持仓期冻结的对冲比例与动态模型的对照；
- 宽点差腿、资金费窗口、开盘事件和周末的单独标记与消融。

不要以高 R²、ADF 通过或单一半衰期估计宣称可交易；还需观察残差定义是否漂移、方向是否与实际篮子一致、回归速度、成本后的收益和尾部风险。若模型定义的对冲关系不能在市场中被真实执行，应把它限制为研究或 shadow 信号。

## 5. 分阶段准入

按照风险逐步扩大证据，而不是直接扩大资金：

1. 固定数据夹具与历史回放：验证数学、方向、时间和状态转移。
2. 持续 dry-run/shadow：用实时数据产生完全相同的信号、风险判断、订单计划和事件日志，但不发送订单。
3. 受限环境或极小额度：核对实际成交、费用、滑点、订单生命周期和恢复路径。
4. 限额实盘：只有当净收益、执行偏差、回撤、异常率和人工处置能力都满足预先定义门槛后再逐级放量。

每一级都需要通过指标和回退条件。例如：数据完整、无未解释的 pending/仓位差异、实际成本不超过模型容忍度、close-all 与重启恢复演练完成。阶段之间的策略、配置、资金和环境应可追溯；任何实盘异常优先回到冻结和对账，而不是继续采样来“等它恢复”。
